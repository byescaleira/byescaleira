### Working principles

1. **Native first** — platform APIs before cross-platform shortcuts.
2. **AI-augmented** — AI accelerates the craft; humans own the outcome.
3. **Design = architecture** — spacing, motion, typography, and interaction are engineering decisions.
4. **Ship, then polish** — working software in production beats perfect branches.
